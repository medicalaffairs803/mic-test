# Mic Test Pro

A free, browser-based microphone testing tool. Check your microphone input, sound quality, noise level, and latency instantly — no download or installation required.

🔗 Live site: https://medicalaffairs803.github.io/mic-test/

## Features
- Real-time waveform visualizer
- Input level and noise detection
- Latency measurement
- Dedicated test pages for Zoom, Discord, gaming headsets, Bluetooth, and USB microphones

## Tech
Built with vanilla HTML, CSS, and JavaScript (Web Audio API) — no frameworks, no build step.
